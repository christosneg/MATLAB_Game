# MATLAB Game

Welcome to the **MATLAB Game** repository! This project is a game developed entirely in MATLAB, showcasing interactive gameplay mechanics and modular design. It demonstrates concepts such as object-oriented programming, graphics, and logic building in MATLAB.

## Features
- **Player Interaction**: Control the player to achieve game objectives.
- **Enemy AI**: Interact with intelligent enemies designed to challenge the player.
- **Modular Codebase**: Separate files for game logic, player, and enemy behaviors for easier understanding and modification.

## Getting Started

### Prerequisites
- MATLAB R2020b or later.
